## 注意点
- **FOMC は日本の早朝**＝流動性が薄くスプレッドが開きやすい。**ロットを更に絞る**。
- 会見（日銀15:30 / パウエル03:30）は**声明後の二段目の波**を作りやすい。初動のヒゲは追わず**ブレイク確定後**に。
- 介入は**時刻不定**。bot はイベント窓に関係なく常時監視。
