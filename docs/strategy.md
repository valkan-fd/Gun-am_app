# 戦略ドキュメント — みんなのFX 30万円 / 90lot / 60日 + イベント高ボラ

> 結論を先に。**あなたの本当の勝ち筋は「相場で当てること」ではなく「90lot を最小コストで消化してキャッシュバックを確定させること」です。**
> 「最高勝率」を額面どおり"方向を当て続けるbot"と解釈すると、誰も実現できません（できると言う人は嘘です）。
> 一方、キャンペーン報酬は**取引を完了させれば確定**するので、ここに期待値の源泉があります。

> **本リポジトリは 2 つの独立botに分離しています。**
> - 🎯 **高勝率bot**（`run_winrate.py` / §1）… 低リスクで 90lot を消化。高ヒット率・薄利。
> - ⚡ **高ボラbot**（`run_volatility.py` / §2）… 6/16日銀・6/18FOMC・介入で一気に。低勝率・損小利大。
> 役割が逆なので**資金も分けて運用**（目安：高勝率 8〜9割／高ボラ 1〜2割）。

## 1. メイン戦略：90lot 低リスク消化（期待値プラスの本命）

### 1-1. 発想
- キャッシュバックは**ボリューム達成で確定**。だから「勝つ」必要はなく「**出費（スプレッド＋スワップ＋スリッページ）を最小化して 90lot を淡々と積む**」のが最適。
- 90lot = 90万通貨の新規。**1lot×90回**でも**2lot×45回**でも可。60日なら **1.5lot/日**で十分間に合う（`lot_tracker` が残日数からペースを自動算出）。

### 1-2. コスト試算（USD/JPY 想定）
- スプレッド片道 ≒ 0.2銭。1lot 往復のスプレッドコスト ≒ **約20〜40円**。
- 90lot を素直に回しても **スプレッド総額 ≒ 2,000〜4,000円**＋スリッページ。
- キャンペーン報酬がこれを**大幅に上回る**ので、**たとえ売買損益がトントン〜小幅マイナスでも全体は大幅プラス**。これが本質。

### 1-3. 実装（`src/strategy_campaign.py`）
- **平均回帰スキャルプ**：EMA(50) から **1.2×ATR** 以上乖離 ＋ RSI が 30以下/70以上の行き過ぎ → 中心回帰方向へ。
- TP 浅め(0.6×ATR)・SL やや広め(1.0×ATR)・**小ロット固定**。**無風(min_atr未満)/荒れすぎ(max_atr超)はスキップ**（荒れはイベント側に委譲）。
- 狙いは「わずかな逆張りエッジ＋低コストでロットを稼ぐ」。**大勝ち狙いではない**。

### 1-4. 運用ルール（手動でも同じ）
1. **取引時間**：流動性が高くスプレッドが安定する **日本時間 16:00〜翌2:00（欧州〜NY）** を中心に。早朝・週明け窓・指標直後の拡大時間帯は避ける。
2. **イベント前後は消化を止める**（6/16 昼〜夕、6/18 早朝）。消化はイベント外の平常時に。
3. **同時保有は 1〜2lot まで**（30万円・USD/JPY≒157で必要証拠金は1lotあたり約6.3万円。証拠金維持率に余裕を持たせ、最大でも2〜3lot）。
4. **毎日少しずつ**。期限直前にまとめて回すと、ボラ急変で建てた瞬間に逆行 → 余計な損失。`lot_tracker` の推奨ペースに従う。

## 2. イベント戦略：6/16 日銀・6/18 FOMC・為替介入で"一気に"（高リスク・高ボラ）

> ここは**当たれば大きいが外れも大きい**領域。**勝率は下がりボラ（変動）が上がる**。
> "一気に稼ぐ"は"一気に溶かす"と表裏一体。**必ず小ロット＋逆指値必須**。資金全部を賭けない。

### 2-1. なぜ高勝率と"一気に稼ぐ"は両立しにくいか
- 高勝率＝浅利・薄リスクの積み上げ（メイン戦略）。
- "一気に"＝低勝率でも一発のリワードが大きい賭け（イベント）。
- **両立はしない**。だから**資金を二分**する：大半をメインの確実なロット消化に、ごく一部（例：投入資金の1〜2割／1lot単位）をイベントの宝くじ枠に。

### 2-2. モードA：ブレイクアウト追随（`strategy_event.breakout_signal`）
- イベント直前の **直近レンジ(high/low)** を基準に、**確定的な上抜け/下抜け（buffer=0.25×ATRでダマシ除け）**で順張り。
- **初動のヒゲは取りに行かない**（スプレッド拡大・スリッページで不利）。**ブレイク確定後に乗る**。
- TP=2.5×ATR、SL=レンジ反対側 or 1.2×ATR の**近い方**。損小利大。

### 2-3. モードB：為替介入フェード（`strategy_event.intervention_signal`）
- シナリオ：**USD/JPY が高値圏（既定 160円接近）で短時間に急騰** → 財務省/日銀の**円買い介入**で急落しやすい（2022・2024年に複数回、数分で3〜5円急落の実績）。
- ロジック：介入警戒水準への接近 ＋ 直近の急騰速度超過 → **売り目線シグナル（高優先通知）**。
- **注意**：介入の有無・時刻は**誰にも予測不能**。窓開け・スプレッド拡大・逆指値の滑りが激烈。**必ず小ロット、逆指値を必ず置く、ナンピン禁止**。

### 2-4. イベントの実戦タイムライン（JST）
- **6/16（日銀）**：12:00前後に結果 → 15:30 会見で乱高下しやすい。会見の発言で往復することが多い → **ブレイク確定待ち**。会合前にポジは軽くしておく。
- **6/18 03:00（FOMC声明）/03:30（会見）**：日本の早朝。**流動性が薄くスプレッドが開きやすい** → ロットを更に絞る。声明とドット（金利見通し）で初動、会見で二段目。
- **介入**：時間帯を問わず発生し得る。bot は窓に関係なく**常時介入監視**。

### 2-5. やってはいけないこと（破産回避）
- ❌ 指標発表の瞬間に成行でフルレバ。→ スリッページでSLが意味をなさない。
- ❌ 逆行を「介入が来るはず」とナンピン。→ 介入が来なければ即ロスカット。
- ❌ イベントを跨いで大口を放置して就寝。→ 既定が notify モードなのはこのため。
